SWIMMING POOL MANAGEMENT SYSTEM 

PROJECT OBJECTIVE 
• The main objective of the Swimming Pool Management System is to develop a simple Javabased application to manage swimming pool member information using JDBC and MySQL.              

The system allows the user to:  

➔ Add new swimming pool member details. 
➔ Display all member details. 
➔ Search for a member using Member ID. 
➔ Update existing member information. 
➔ Delete member information. 
➔ Perform basic CRUD (Create, Read, Update, Delete) operations. 
➔ Use Scanner to accept user input. 
➔ Use switch-case to provide a menu-driven system. 
➔ Use  interface named SwimmingPoolInterface and implement it in the SwimmingPool class. 
➔ Store and retrieve member data from a single MySQL table using JDBC.
