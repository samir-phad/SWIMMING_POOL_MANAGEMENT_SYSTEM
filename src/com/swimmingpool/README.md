# 🏊 SWIMMING POOL MANAGEMENT SYSTEM

## 📌 Project Objective

The main objective of the **Swimming Pool Management System** is to develop a simple Java-based application to manage swimming pool member information using **JDBC and MySQL**.

## 🚀 Features

The system allows the user to:

- ➕ Add new swimming pool member details
- 📋 Display all member details
- 🔍 Search for a member using Member ID
- ✏️ Update existing member information
- 🗑️ Delete member information
- 🔄 Perform basic CRUD operations
  - Create
  - Read
  - Update
  - Delete
- ⌨️ Use `Scanner` to accept user input
- 📑 Use `switch-case` to provide a menu-driven system
- 🔌 Use the `SwimmingPoolInterface` interface and implement it in the `SwimmingPool` class
- 🗄️ Store and retrieve member data from a MySQL table using JDBC

## 🛠️ Technologies Used

- Java
- JDBC
- MySQL
- SQL
- VS Code
